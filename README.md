##📊 Imersão Python: Análise de Dados Salariais##
Este projeto foi desenvolvido durante a Imersão Python da Alura, focado em explorar, tratar e visualizar dados reais de salários na área de dados.

📝 Sobre o Projeto
O objetivo principal foi realizar uma análise exploratória de um conjunto de dados contendo informações sobre remuneração, cargos e níveis de experiência. Através do Python, buscamos identificar tendências e responder perguntas como: "Quais são os 10 cargos com as maiores médias salariais?"

🛠️ Tecnologias Utilizadas
Python 3.x

Pandas: Para manipulação e tratamento dos dados.

Matplotlib / Seaborn: Para criação de visualizações e gráficos.

Streamlit: Hospedagem do dashboard.

🚀 Principais Análises Realizadas
Limpeza de Dados: Tratamento de valores nulos e conversão de moedas.

Agrupamentos: Uso de .groupby() e .mean() para encontrar médias por cargo.

Top 10 Salários: Identificação das posições mais valorizadas no mercado de dados.

Visualização: Gráficos de barras comparativos para facilitar a leitura dos insights.
